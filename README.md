# Diário de Treino

App de registro de treino que funciona sem internet. Os registros ficam no celular e são enviados para uma planilha do Google quando há conexão.

Publicado com GitHub Pages a partir da pasta raiz do branch `main`.

Nenhum dado de treino nem chave de acesso fica neste repositório: a URL do script e a chave são digitadas em Ajustes, dentro do app, e ficam só no aparelho.

Ao mudar qualquer arquivo, aumente `VERSAO` em `sw.js` para os celulares baixarem a versão nova.
